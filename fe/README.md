# Frontend (Next.js)

## Run nhanh

```bash
cd fe-next
npm install
npm run dev
```

Mở trình duyệt:
- http://localhost:3000

## Build production

```bash
cd fe-next
npm run build
npm run start
```

## Ghi chú
- Đây là giao diện portal sinh viên HCMUTE mockup.
- Dành cho việc thiết kế UI trước khi tích hợp Laravel/BE thật.
